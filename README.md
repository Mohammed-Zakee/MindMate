# MindMate AI 🧠✨

> **Empowering Student Wellness & Academic Excellence through Intelligent AI.**

MindMate AI is a modern, intelligent, full-stack platform designed to help students navigate the complexities of university and school life. By blending AI-driven emotional support, smart productivity tools, and advanced academic planning, MindMate AI acts as a dedicated companion for mental wellness and high-performance learning.

---

## 🌟 Vision
To bridge the gap between academic pressure and mental health, providing students with a calming, intelligent, and supportive ecosystem that prevents burnout and fosters long-term success.

---

## 🚀 Core Pillars

### 🧘 Wellness & Mental Health
- **AI Emotional Support:** Real-time sentiment analysis and empathetic conversations to detect stress, anxiety, and burnout.
- **Mood Tracking:** Daily logs with interactive analytics to visualize emotional trends.
- **Wellness Journal:** A safe space for gratitude journaling and daily reflections.

### 📈 Productivity & Performance
- **Smart Study Planner:** AI-optimized schedules that adapt to your deadlines and learning pace.
- **Task Management:** A sleek, drag-and-drop productivity hub with Pomodoro integration.
- **Gamification:** Earn XP, badges, and maintain streaks to stay motivated.

### 🎓 Academic Support
- **AI Academic Assistant:** Get guidance on study techniques, exam prep, and complex topics.
- **Resource Hub:** Curated learning materials and personalized study recommendations.
- **Focus Mode:** Minimalist interface designed to keep you in the "flow" state.

## 🎨 Design Philosophy
MindMate AI is built with a **Calm & Premium** aesthetic:
- **Glassmorphism:** Soft, translucent layers for a modern feel.
- **Fluid Animations:** Powered by Framer Motion for a seamless experience.
- **Color Palette:** Soft Blues, Purples, and Cyans to reduce visual stress.
- **Responsive:** Fully optimized for Mobile, Tablet, and Desktop.

## 🛠️ Getting Started (Development)

### Prerequisites
- Node.js (v18+)
- MongoDB Atlas or PostgreSQL instance
- API Key (Gemini or OpenAI)

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mohammed-Zakee/MindMate.git
   ```
2. **Install Dependencies:**
   ```bash
   # Client
   cd client && npm install
   # Server
   cd server && npm install
   ```
3. **Environment Variables:**
   Create a `.env` file in the server directory:
   ```env
   PORT=5000
   MONGO_URI=your_mongodb_uri
   JWT_SECRET=your_secret_key
   AI_API_KEY=your_gemini_api_key
   ```
4. **Run the App:**
   ```bash
   # Start Server
   npm run dev
   ```
